# Approved AMD reference files

Place the downloaded PDFs in this folder when building the Kaggle reference Dataset.
Recommended filenames:

```text
agerelated-macular-degeneration-pdf-1837691334853.pdf
Age-Related Macular Degeneration PPP.pdf
```

An optional Beckman classification PDF can be added later. The selection policy is
stored in `knowledge_base/reference_manifest.yaml`. Notebook 14 first produces a
page-level audit and then embeds only approved pages.

Do not commit copyrighted PDFs to GitHub. Upload them as a private Kaggle Dataset.
